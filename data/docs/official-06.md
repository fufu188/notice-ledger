为确保作品不是直接复制已有开源项目，且其AI演进过程真实、可复现，参赛团队必须在截止时间前通过大赛官网统一提交以下材料。以下要求省赛与国赛一致。

2.1 代码仓库与演进记录

托管平台：GitHub 或 Gitee，须设为 Public 或提供评审访问权限。

Git 提交日志（关键）：必须保留完整的、细粒度的 Git 提交历史。禁止一次性提交（即 initial commit 就包含全部功能）。每次提交应对应一次与 AI 的核心对话或一个功能模块的落地。

AI 对话历史导出的 Prompt 历史快照：使用 AI 工具需要导出和 AI 的对话历史，如果 AI 工具不支持导出，可以截图或者录屏。须包含至少 3 个核心功能迭代时与 AI 交互的完整 Prompt 链，包含你的 Prompt 提问、AI 的修改建议、以及你如何引导 AI 修复 Bug 的过程。

2.2 复现性声明与重现指南（README.md）

10 分钟极速复现指南：提供完整的环境配置说明、依赖清单、环境变量模板。

2.3 演示视频与技术文档

演示视频：5 至 8 分钟，MP4 格式，1080p。除功能演示外，必须包含至少 2 分钟的「AI 协同过程复现展示」，例如在录屏中展示你是如何输入某段 Prompt 让 AI 生成核心模块，或者如何引导 AI 解决某个顽固 Bug 的。

技术文档：PDF 格式，不超过 30 页。需重点阐述：意图控制策略（你是如何设计上下文和 Prompt 的）、架构设计（AI 生成的代码采用了什么架构，你如何约束它）、可复现性论证。

比赛环境：本赛项对技术栈不设强制限定，鼓励使用能最大化释放 AI 生产力的前沿工具。AI 辅助编程 IDE/工具包括 Cursor、Windsurf、Trae、通义灵码等；技术栈推荐 React/Next.js、Vue/Nuxt、Python/FastAPI、Node.js、Go、Flutter 等。

省赛作品提交表单另有独立要求：作品介绍文档须包含项目详情及使用方式、项目亮点、AI 技术落地使用情况、关键技术、相关图片、是否已发表或获奖、若基于其他项目优化的说明；演示视频不得使用百度网盘链接，须上传至 B 站、抖音等可公开访问的平台。
