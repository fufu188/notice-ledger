## AI 的修改建议 / 生成内容

1. 场景定为「校务 / 赛事通知可信问答助手」，核心不是普通文档问答，而是：口径差异检测 + 引用溯源 + 时效性/来源权重 + 无依据拒答 + 自建评测集。选它的证据是交接文档自身记录的 11.18 三重口径与 1 月底 / 12.27 时间线矛盾——用户本人即受影响用户。
2. 架构：检索 / 冲突检测 / 回答核心零第三方依赖（本机实测缺 fastapi/uvicorn/pydantic）；FastAPI 仅作薄封装；LLM 为可选增强，只通过环境变量注入，缺失或失败自动降级到离线抽取，并在返回值里标 `llm_degraded`。
3. 意图控制显式写进 `app/answer.py` 的 `SYSTEM_PROMPT`：只用检索片段、逐条引用、口径不一致必须并列、资料不足必须拒答、整理稿不写成官方定论。
4. 生成文件：`requirements.txt`、`.env.example`、`app/`（models / loader / chunker / retriever / answer / cli / main）、`tests/test_core.py`、`data/docs/demo-0*.md`、`README.md`、本文件。
