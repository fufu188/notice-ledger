# P-010｜科技粒子动态风格整体视觉升级（保留功能与结构）

- 日期：2026-11-09 22:26 — 22:35
- 用户 Prompt（原文）：**「基于已创建的仓库 https://github.com/fufu188/notice-ledger.git，请对项目页面进行整体视觉升级，采用"科技粒子动态风格"（即带有流动粒子、动态光效、深色科技感背景的界面风格，可先调研此类风格的设计参考），使页面呈现强烈的科技感和交互体验。要求：1) 先确定统一的设计语言（配色、动效、字体、光影层次）；2) 逐一美化每个页面组件（导航、卡片、按钮、表格、表单等），保持风格一致；3) 加入适当的动态效果（如粒子背景、悬停反馈、过渡动画）以增强交互感，但注意性能与可维护性；4) 保持原有功能与页面结构不变，仅做视觉与交互层面的优化。」**

## 一、调研（先查再写，不凭印象）

两轮检索共 10 组结果，采信 5 个一手参考（含两篇 2026 年实践文章、一份完整设计 token 体系、一个设计系统文档、一份 synthwave 主题规范），提炼出的硬约束直接落进了实现：

| 调研结论 | 来源要点 | 落地方式 |
|---|---|---|
| 粒子用 Canvas 不用 DOM；rAF 驱动；`visibilitychange` 暂停；tab 隐藏即停 | heroprompts 2026 动效实践 | 全部实现 |
| 粒子数随视口缩放；移动端 30–50 或禁用 | 同上 + empire-ui | `count = clamp(W*H/16000, 24, 85)`，<768px 再 ×0.45 |
| `prefers-reduced-motion` 必须支持（WCAG 2.1 AA） | 多源一致 | CSS 媒体查询关动画 + JS 不启动粒子循环 |
| 避免动画 blur/box-shadow，只用 transform/opacity | heroprompts 性能规则 | 所有 `transition` 的 property 白名单化 |
| additive blending（`lighter`）几乎零成本地制造霓虹感 | empire-ui 粒子系统 | 粒子层用 `lighter`，UI 层恢复 `source-over` |
| 玻璃拟态 = backdrop-blur + 半透明底 + ghost border | crypto aesthetic / synthwave 两套体系 | header/footer/aside/卡片统一应用 |
| 深空底 + 青/紫霓虹双强调的成熟 token 体系 | Crypto Aesthetic 色板 | 取 `#060a13` 底 + `#38d9ff` 青 + `#8b7bff` 紫 |
| devicePixelRatio 高分屏代价 4× 像素，"快 vs 清"二选一 | empire-ui FAQ | DPR 上限 1.5 折中 |
| 设计 token 必须服务于业务语义，不是 CodePen demo | empire-ui 集成建议 | 语义色（ok/warn/danger）保留并霓虹化，不破坏"可信裁决"信息层级 |

**不引入的东西（及其理由）**：Google Fonts（破坏零依赖/离线复现硬约束）、particles.js 等 CDN 库（同上）、WebGL/Three.js（粒子量级远不需要）、动画 box-shadow / 文字 glow 动画（重绘成本）。

## 二、统一设计语言（token 化，全部在 `:root`）

| 层 | 决策 |
|---|---|
| 配色 | 深空 `#060a13` + 双静态径向光晕；青 `#38d9ff`（行动/链接/强调）+ 紫 `#8b7bff`（渐变配对）；语义色霓虹化（ok `#00e39c` / warn `#fbbf24` / danger `#ff5d73`） |
| 动效 | 令牌 `--ease: cubic-bezier(.33,1,.68,1)`、`--t-fast .16s`、`--t-med .3s`；进场 fade-rise；悬停 translateY(-1px) |
| 字体 | 系统栈不变（零依赖约束）；标题渐变填充 + letter-spacing；数据 `font-variant-numeric: tabular-nums` |
| 光影 | 三级：粒子层（z0）→ 玻璃面板（backdrop-blur 12–14px + ghost border）→ 发光徽章/按钮（静态 box-shadow + 内高光） |
| 边界 | header/footer 上下缘用青紫渐变 1px 光线替代实线，呼应"账本台账"的边界语义 |

## 四、粒子背景实现要点（独立 IIFE，约 70 行，零依赖）

- 星座效果：粒子间 <120px 连线（透明度随距离衰减），鼠标 160px 内加强连线（青白光）——"系统在感知你"的隐喻
- 青紫双色粒子 + `lighter` 混合发光；`pointer-events:none` 不挡 UI
- rAF + `visibilitychange` 暂停恢复；`resize` 被动监听重建粒子场
- `prefers-reduced-motion`：CSS 隐藏画布 + JS 短路，静态渐变底保底

## 六、诚实边界

- 视觉模型对截图的 OCR 会误读渐变标题（把「校务」认成近形字），实际渲染正常；标题渐变在极旧浏览器无 `background-clip:text` 时理论上有降级风险，当前目标环境（Chromium/Edge）实测无问题。
- 粒子层的鼠标交互在无头截图中不可见（无鼠标事件），仅在真实交互中生效。
- `backdrop-filter` 在大量卡片堆叠时有合成成本；当前同时可见卡片数通常 <10，实测流畅；若极端长对话出现掉帧，可去掉 `.card` 的 blur（一行 CSS）。
