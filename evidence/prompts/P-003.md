
## AI 的修改建议 / 生成内容

1. 不再反复换源重试，不引入不可信安装源；`FastAPI` 主实现 `app/main.py` 保留不动，等技术栈依赖可装时直接可用。
2. 新增 `app/server.py`：标准库 `http.server` 实现 `GET /health`、`GET /sources`、`POST /ask`，复用零依赖核心，接口语义与 FastAPI 版一致。
3. `--selftest` 模式：临时端口自启 → 探测三个接口 → 自动关闭，不留常驻进程。
4. 用 `urllib.request.build_opener(ProxyHandler({}))` 绕过沙箱注入代理对 `127.0.0.1` 的劫持（该坑已记在 `findings.md` 第 5 节），否则本地自测会被代理拦截。
5. 在 README 明确写出「FastAPI 依赖未装成功、服务层未运行验证」，不把降级包装成"已完成"。
